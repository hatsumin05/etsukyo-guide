# data.json のデータ仕様

サイト(`index.html`)が読み込む唯一のデータファイルです。この仕様に沿っていれば、
`node scripts/validate-data.mjs` の検証を通過します。

## 全体の構造

```jsonc
{
  "lastSynced":   "2026-09-04",                  // 必須 / YYYY-MM-DD
  "lastSyncedAt": "2026-09-04T06:10:00+09:00",   // 必須 / ISO 8601(時刻・タイムゾーンつき)
  "sources":    [ /* 調査対象サイト */ ],
  "candidates": [ /* 体験・イベント */ ]
}
```

`lastSyncedAt` は日次の収集タスクが走った日時です。サイト右上の「最終更新」表示と、
GitHub Actions の鮮度チェック(48時間以上更新がなければ失敗)の両方がこの値を見ます。
**更新のたびに必ず現在時刻に書き換えてください。**

## sources[] の各項目

| フィールド | 必須 | 内容 |
|---|---|---|
| `id` | ✅ | 一意な識別子(半角英数とハイフン) |
| `name` | ✅ | サイト名 |
| `url` | ✅ | `https://` で始まるURL |
| `note` | ✅ | どんな情報が載っているかのメモ |

## candidates[] の各項目

### 既存フィールド(すべて必須)

| フィールド | 内容 |
|---|---|
| `id` | 一意な識別子。**重複するとエラー**になります |
| `title` | 体験・イベント名 |
| `org` | 主催団体 |
| `type` | 種別(`コンテスト` / `オンラインプログラム` / `ワークショップ` / `説明会` など) |
| `audience` | 対象者(人間が読む自由文) |
| `deadline` | 日程の**原文**。公式サイトの表記をそのまま残す(例: `開催9/6・13、申込締切9/5(土)23:59`) |
| `summary` | 1〜2文の概要 |
| `tags` | 興味タグの配列。`index.html` の `TAG_GROUPS` にある語のみ有効 |
| `url` | 公式ページURL(`http(s)://` で始めること) |

`deadline` は人間向けの表示用として残します。**絞り込み・並べ替えには使いません。**
機械判定は下の構造化フィールドだけを見ます。

### 構造化フィールド(すべて必須。値が不明なら `null`)

| フィールド | 型 | 内容 |
|---|---|---|
| `eventStart` | `"YYYY-MM-DD"` \| `null` | 開催初日。**これが無いと「これから1ヶ月の開催」一覧に出ません** |
| `eventEnd` | `"YYYY-MM-DD"` \| `null` | 開催最終日。単日開催なら `eventStart` と同じ値 |
| `applyStart` | `"YYYY-MM-DD"` \| `null` | 応募受付の開始日。不明なら `null`(締切前なら受付中とみなされます) |
| `applyEnd` | `"YYYY-MM-DD"` \| `null` | 応募締切日。**これが無いと「応募受付中」一覧に出ません** |
| `format` | 下の5値のいずれか | 開催形式 |
| `venue` | オブジェクト \| `null` | 会場情報。`format` が `onsite` / `hybrid` のときは設定すること |
| `onlineTool` | 文字列 \| `null` | 使用ツール(`Zoom` など)。不明なら `null` |

日付はすべて `YYYY-MM-DD`(ゼロ埋め)で書きます。`2026-9-6` や `2026年9月6日` は**エラー**です。
時刻は構造化フィールドには含めません(必要なら `deadline` の原文に残します)。

### `format` に使える値

| 値 | 意味 | サイト上の表示 |
|---|---|---|
| `online` | オンライン開催 | 🌐 オンライン開催 |
| `onsite` | 会場に集まって開催 | 📍 会場開催・(都道府県) |
| `hybrid` | オンラインと会場の併催 | オンライン・会場 併催 |
| `submission` | 作品をWeb/郵送で提出する応募型。**来場イベントなし** | Web/郵送で応募(来場なし) |
| `unknown` | 公式サイトを見ても判断できなかった | 開催形式は公式サイトで確認 |

コンテスト・コンクールの多くは `submission` です。`submission` の場合は
`eventStart` / `eventEnd` を `null` にし、`applyEnd` に締切を入れてください。

**推測で `online` / `onsite` を書かないこと。** 判断できないときは `unknown` にします。
誤った会場情報は、生徒が現地に行ってしまう事故につながります。

### `venue` の構造

```jsonc
"venue": {
  "name":       "仙台市市民活動サポートセンター",  // 会場名 / 不明なら null
  "address":    "宮城県仙台市青葉区一番町4-1-3",   // 住所 / 不明なら null
  "prefecture": "宮城県"                          // 都道府県 / 不明なら null
}
```

3つのキー以外を入れると**エラー**になります。会場情報がまったく無い場合は `venue` 自体を `null` に。
一覧のバッジには `prefecture` → `name` → `address` の順で最初に見つかった1つが表示され、
詳細パネルには 3つすべてが表示されます。

## 検証の実行

```bash
node scripts/validate-data.mjs                    # 構造チェックのみ
node scripts/validate-data.mjs --max-age-hours 48 # 鮮度チェックも行う
```

- **エラー**があると終了コード 1 を返し、GitHub Actions が失敗します
- **警告**は失敗させません(「applyEnd が無いので応募受付中一覧に出ない」等のお知らせ)
