# 越境体験ガイド(Vercel版)セットアップ手順

このページは、Claudeへのログインなしで**誰でも見られる状態**にするためのVercel版です。中身のデザインは元のClaude版と同じで、必要なファイルは `index.html` と `data.json` の2つだけの、シンプルな静的サイトです。

毎日の情報更新は、追加のAPI課金が発生しないよう **Claude側の定期実行タスク**(はつみんさんが今お使いのプランに含まれる範囲)で行い、その結果をGitHubリポジトリに直接反映します。GitHubへの反映をきっかけに、Vercelが自動で再デプロイしてサイトの内容が更新される仕組みです。Vercel自体にはサーバーレス関数もAPIキーも不要なので、追加費用は基本的にかかりません(Vercelの無料枠のみで運用できます)。

## 全体の流れ(所要時間目安 10分程度)

1. GitHubにこのプロジェクトを置く
2. Vercelにインポートしてデプロイする
3. 自動更新用に、限定権限のGitHubトークンを発行してClaudeに共有する

以降はすべて自動で動きます。

---

## 1. GitHubにこのプロジェクトを置く

1. GitHubで新しいリポジトリを作成(例: `etsukyo-guide`)。公開・非公開はどちらでも構いません
2. お送りしたファイル一式(`index.html`・`data.json`・このREADME)を、そのリポジトリのルート(トップ階層)にアップロード
   - GitHubのWeb画面から「Add file → Upload files」でドラッグ&ドロップするのが簡単です

## 2. Vercelにインポートしてデプロイする

1. https://vercel.com/new にアクセス
2. 先ほどのGitHubリポジトリを選択して「Import」
3. 設定は特に変更せず、そのまま「Deploy」を押す(Framework Presetは「Other」のままでOKです)
4. 数十秒でデプロイが完了し、`https://(プロジェクト名).vercel.app` のようなURLが発行されます。この時点でもう、誰でもアクセスできる状態です

## 3. 自動更新用に、限定権限のGitHubトークンを発行する

Claude側の毎日の自動更新タスクが、このリポジトリの `data.json` だけを書き換えられるようにするためのトークンです。以下の手順で、**このリポジトリだけに使える最小限の権限**のトークンを作成してください。

1. GitHubの右上のアイコン →「Settings」→ 左メニュー下の方の「Developer settings」
2. 「Personal access tokens」→「Fine-grained tokens」→「Generate new token」
3. 設定内容:
   - Token name: 任意(例: `etsukyo-guide-auto-update`)
   - Expiration: お好みで(1年など。期限が切れたら再発行し、私に新しいものを教えてください)
   - Repository access: 「Only select repositories」を選び、先ほど作成したリポジトリのみを選択
   - Permissions →「Repository permissions」→「Contents」を **Read and write** に設定(他はすべて「No access」のままでOKです)
4. 「Generate token」を押すと `github_pat_...` から始まる文字列が表示されるので、コピーする(この画面を閉じると二度と表示されないので注意)

トークンを発行したら、このチャットに次の2つを送ってください:

- リポジトリ名(例: `はつみんさんのGitHubユーザー名/etsukyo-guide`)
- 発行したトークン文字列

受け取ったら、Claude側の毎日の自動更新タスクの設定にそのトークンを組み込み、以後は完全に自動で「調査 → GitHubへ反映 → Vercelが自動再デプロイ」が回るようにします。

**トークンの扱いについて**: このトークンは、ご指定のリポジトリの中身を書き換えられる力を持つ認証情報です。上記の設定(このリポジトリのみ・Contents権限のみ)にしていれば、万一の際の影響範囲は最小限に抑えられます。用がなくなった場合や不安に感じた場合は、GitHubの「Fine-grained tokens」の画面からいつでも即座に無効化(Revoke)できます。

## サイトの構成(2026-09-04 追記)

トップの3つのタブで表示を切り替えられます。

| タブ | 内容 | 並び順 |
|---|---|---|
| タグで探す | 従来どおり。興味タグを選ぶと合う体験が並びます | タグ一致数の多い順 |
| 応募受付中 | 本日が応募期間内のものを**すべて**表示 | 応募締切が近い順 |
| これから1ヶ月の開催 | 開催日が本日から30日以内のもの | 開催日が近い順 |

各カードには開催形式のバッジ(オンライン開催 / 会場開催・都道府県 / Web・郵送で応募 など)が付き、
「詳しく見る」を押すと開催日・応募期間・会場の住所・参加方法などを展開して確認できます。

日付の判定はブラウザ側で「その日の日付」を見ているため、**日付で絞り込む2つのタブは、
データを触らなくても毎日自動で最新の内容になります**。日次の更新作業は、新しい体験の収集だけです。

- データの書き方: [docs/data-schema.md](docs/data-schema.md)
- 日次更新タスクの指示文: [docs/daily-update-prompt.md](docs/daily-update-prompt.md)

### データの検証

`data.json` を手で直したときは、コミット前にこれを実行すると壊れていないか確認できます。

```bash
node scripts/validate-data.mjs
```

GitHub Actions でも自動で走ります。

- `main` への push / Pull Request のたびに → 構造チェック(日付の形式、開催形式の値、ID重複など)
- 毎日 09:00 JST に → 構造チェック + 鮮度チェック。`lastSyncedAt` が48時間以上更新されていなければ
  **ワークフローを失敗させて通知**します(＝日次の収集タスクが止まったことに気づけます)
- 実行ログは GitHub の「Actions」タブに残ります

## 運用が始まったら

- サイトの内容は毎日、Claude側のタスクが登録済みのサイト(Qulii・登竜門など)を調べて自動更新します
- 調べるサイトを増やしたいときは、いつでもこのチャットで「〇〇というサイトも見て」と伝えてください。手動でファイルを添付する必要はありません
- これまでClaude側で運用していた「越境コンパス」(先生用の編集ツール)は、そのまま先生同士の情報共有・手動登録用として使い続けられます。そちらで先生が候補を追加・編集した内容も、翌日の自動更新のタイミングでこのVercel版に反映されます
- 旧「越境体験ガイド」(Claudeの公開アーティファクト版)と、その毎日の自動更新タスクは、Vercel版が問題なく動くことを確認できたら停止して構いません。落ち着いたタイミングで教えてください
